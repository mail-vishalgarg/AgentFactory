Key Design Principle
The LLM never directly calls the MCP server.

LangGraph's stub tools give the LLM enough information (name + input schema) to decide which tool to invoke and with what arguments — but the stubs themselves do nothing. The actual HTTP call is always made by _execute_real_tool(), which runs after the graph pauses at the interrupt_before=["tools"] gate.

This separation means the backend controls every tool execution — enforcing the approval gate for write/destructive operations — regardless of what the LLM requests. The LLM is a planner, not an executor.
