LangChain — The Building Blocks

Provides the individual primitives: the LLM wrapper, tool definitions, and message types. Think of it as the parts of the agent.

Planner · Tools · LLM

LangGraph — The Orchestrator

Wraps LangChain primitives into a stateful graph that can pause, resume, checkpoint, and enforce approvals mid-run. It's the engine.

⚡ Key Design Principle
LangChain is the parts supplier — it provides the LLM, the tool schema wrappers, and the message types.
LangGraph is the engine — it takes those parts and runs them inside a stateful graph that can pause, checkpoint, and resume.

The critical feature that made LangGraph necessary here is interrupt_before=["tools"]. Without it, there is no way to intercept a tool call, check if it's a write/destructive operation, and ask the user to approve it before it runs. LangChain's AgentExecutor runs straight through to the end — you can't stop it in the middle.
